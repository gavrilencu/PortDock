## Full-width pages and cleaner tabs

### Changes

- **Pages use the full width of the window.** The content no longer stops at a fixed width with empty space on the sides.
- **Tabs without scrollbars.** When the tabs of an application, database, service or server don't fit, the extra ones go into a **More** menu. The active tab always stays visible.
- **Tables** that are wider than the screen still scroll sideways, but their scrollbar only shows when you point at the table.
- **Release notes in the update dialog** are now formatted (headings, lists, code, links).
- **Every release now includes installation instructions** for a new server, with the installer or the prebuilt Docker image of that version.
