## The application's port, detected and explained

An application whose port did not match the one its container listens on (a Dockerfile serving nginx on port 80, with the default port 3000) failed on Kubernetes after several minutes, with only *CrashLoopBackOff* to go by. PortDock now picks the right port to begin with, and says so when it is wrong.

### Fixes

- **The port of a Dockerfile is detected.** A repository with a Dockerfile now gets the port its final stage declares with `EXPOSE` (`EXPOSE 80` → port 80), instead of 3000 every time. Without `EXPOSE`, or with `EXPOSE $PORT`, the port stays 3000.
- **A port that does not match is reported before the deployment goes on.** After the build, PortDock reads the ports the image declares. When the application's port is not one of them, the log says so: *The image declares port 80 (EXPOSE), but the application's port is 3000…*
- **On Kubernetes, a pod that never answers fails the deployment at once.** A container restarted before it ever passed its health check had its whole startup time already, so PortDock no longer waits through the back-off of every restart (about six minutes for five restarts). The deployment stops right after the first restart, keeps the previous version running, and explains the cause:
  - *Nothing answered on port 3000 within 60 s, and the image declares port 80 (EXPOSE): set the application's port to 80 in Configuration → Network*;
  - or, when the image declares nothing else, to check that the application listens on that port on all interfaces (0.0.0.0, not 127.0.0.1), or to give a slow application a longer health check timeout.
- A container that crashes says so with its exit code (*its container exits with code 1*) instead of only *CrashLoopBackOff*.

### Notes

- An existing application keeps the port it has: if a deployment shows the warning above, change the port in *Configuration → Network* and deploy again.
- Update PortDock on Kubernetes by running the installer again, or with `kubectl -n portdock set image statefulset/portdock portdock=ghcr.io/gavrilencu/portdock:v1.17.1`.
