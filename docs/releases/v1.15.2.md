## Connecting a GitHub App works again

### Fixes

- **Settings → Git → Connect GitHub did nothing after Continue.** The interface's Content-Security-Policy (`form-action 'self'`, added in v1.12.0) blocked the form that sends the app manifest to GitHub, so the browser stayed on the page and only logged *Sending form data to 'https://github.com/…/settings/apps/new' violates the following Content Security Policy directive* in the console. This affected personal accounts, organizations and GitHub Enterprise alike.

  The manifest is now posted by a small hand-off page served by PortDock (`/api/github/manifest/<state>`) with its own policy, which allows sending the form only to the GitHub host you chose (github.com or your GitHub Enterprise URL). The interface keeps its strict `form-action 'self'`. The page opens only for a signed-in administrator, and a setup session older than an hour sends you back to the settings with a message.

### Notes

- Apps registered by hand (App ID and private key) were not affected.
